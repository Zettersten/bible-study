# People — Non-Biblical Reference

Brief bios for people who appear in the bible studies but aren't in Scripture: class teachers, group leaders, participants, and family. Use this file to keep names, roles, and context consistent across studies.

## How to use this file

- **Look up before writing.** When a study mentions a person (for example "Gary says…"), check this file for their role and context before writing the Intro, Class Introduction, or any personal application.
- **Add when new.** When a new non-biblical person appears and isn't listed here, ask Erik for a short bio and add an entry in the format below. Don't guess roles or details.
- **Keep it factual.** Record what Erik confirms. Mark anything that came from an outside source, such as an AI summary or a website, as unverified.
- **Don't publish personal details.** Keep family members to first names and roles. Don't add addresses, phone numbers, or anything Erik hasn't approved for the repo.

## Entry format

```markdown
### Full Name (how the studies refer to them)

- **Role:** Their relationship to the study (teacher, group leader, participant, family, etc.)
- **Context:** Where they appear and what they're known for
- **Background:** Brief bio, with the source noted if not from Erik
- **Notes:** Anything that affects how to write about them
```
